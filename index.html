¿Cómo se usa SmartKiosco?
1
Carga de Stock

Subí tu archivo CSV con el inventario actual del kiosco. El formato debe ser CSV.

2
Análisis automático

El sistema clasifica cada producto: Crítico / Bajo / Normal.

3
Comparador de Ofertas

Para cada producto crítico, SmartKiosco muestra cotizaciones de tus proveedores y resalta la mejor oferta del momento.

4
Agenda de Proveedores

Gestioná tu lista de proveedores con días de visita, horarios de cierre y acceso directo a WhatsApp o web oficial.
